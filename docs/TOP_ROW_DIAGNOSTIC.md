# SMS native top-row diagnostic

`diagnostics/sms-top-row-diagnostic.sms` is an original 32 KiB Master System
ROM generated by `scripts/make_sms_top_row_diagnostic.py`. It draws native
row zero in red and the other 191 active rows in blue. A visible red line at
the very top is the pass condition; an all-blue image means row zero was lost.
The image contains no commercial game data.

On the Rev4 `Sega8bit.NextTrial` core, load this ROM with System set to
Master System or Auto. Check 2× sharp first. For 3× sharp, begin at the
centered crop and **tap R 16 separate times** to move the source crop to row
zero. Holding R does not repeat. Photograph the entire screen and its top
edge in both modes. A red line should be visible at both sizes once 3× is
shifted fully down.

The generator's output is deterministic. Its engine testbench is
`tests/tb_sms_top_row.sv`, included in `scripts/run_tests.py`. The ROM has not
yet been simulated or tested on hardware in this workspace; do not use it to
close [issue #7](https://github.com/czarroland/gamegear-bub/issues/7) until
that verification and the device check are complete.
